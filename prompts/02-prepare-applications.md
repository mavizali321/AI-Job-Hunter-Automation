# PREPARE APPLICATIONS

Take the approved job list from the tracker.

For every job marked READY:
1. Read the complete listing.
2. Identify the 5–8 most relevant requirements.
3. Map each requirement to evidence in PROFILE.md.
4. Create a tailored resume copy if useful, preserving truth.
5. Draft a concise cover letter only when useful/required.
6. Draft application answers.
7. Open the employer's application page with browser tools.
8. Fill all non-sensitive fields that are directly supported.
9. Stop immediately before final submission.
