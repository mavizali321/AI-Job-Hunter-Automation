# SUBMIT APPROVED APPLICATION

Only run this prompt after the user has explicitly approved the exact application.

For each approved application:
1. Re-open/verify the correct company and requisition.
2. Confirm role and candidate identity.
3. Confirm attached resume.
4. Review every answer.
5. Submit.
6. Capture confirmation number or confirmation screen if available.
7. Record:
   company, role, URL, date/time, status=SUBMITTED, confirmation, notes.

If anything changed since approval, STOP and ask for approval again.

Never submit a different role or a different answer set than the approved one.
