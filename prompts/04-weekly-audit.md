# WEEKLY APPLICATION AUDIT

Review tracker/ applications and reports.

Calculate:
- jobs discovered
- qualified jobs
- applications submitted
- interview requests
- rejections
- response rate
- top companies
- top role families
- most common rejection/skip reasons
- repeated missing skills

Then recommend:
1. resume changes
2. portfolio/project changes
3. skill-building priorities
4. companies/role families to increase
5. searches to remove

Do not rewrite factual history without user confirmation.
